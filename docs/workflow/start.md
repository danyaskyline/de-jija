# Start — начать или продолжить сессию

Когда это нужно: новая сессия или автор говорит «продолжаем».

1. Прочитать **только** `START-HERE.md`.
2. Выполнить `git log -5 --oneline` и `git status --short`.
3. Если часть B старше последнего коммита или есть незакоммиченные изменения — доверять git и явно сказать об этом автору.
4. Кратко пересказать состояние, максимум 8 строк: активная задача, что сделано, что не закоммичено, следующий шаг, тесты.
5. Ждать команду автора. Ничего не редактировать и не доделывать самовольно.
