# Sync — записать решения, полученные вне репозитория

Когда это нужно: автор вставляет блок решений, полученных при обсуждении с веб-ИИ.

1. Добавить решение в `docs/decisions.md` в формате ADR этого файла: следующий свободный номер, тот же стиль разделов.
2. Если решение влияет на задачу — добавить его в раздел «Прогресс» активной задачи в `docs/tasks/`.
3. Обновить ЧАСТЬ B в `START-HERE.md`.
4. Если менялась структура файлов — выполнить `npm run map`.
5. Коммит с сообщением `docs: <коротко о сути решения>` и `git push origin main` без `--force`.
