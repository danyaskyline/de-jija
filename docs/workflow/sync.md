# Sync — записать ответ веб-ИИ в репозиторий

Когда это нужно: автор вставил ответ веб-ИИ, полученный по пакету из [`web-ai.md`](./web-ai.md) (формат ответа — там же, в разделе «Формат ОТВЕТ ВЕБ-ИИ»).

1. Добавить решение в `docs/decisions.md` в формате ADR этого файла: следующий свободный номер, тот же стиль разделов. Старые записи не переписываются — исправление это новая запись.
2. Если решение влияет на задачу — добавить его в раздел «Решения» активной задачи в `docs/tasks/`.
3. Обновить ЧАСТЬ B в `START-HERE.md`.
4. Если менялась структура файлов — выполнить `npm run map`.
5. Коммит с сообщением `docs: <коротко о сути решения>` и `git push origin main` без `--force`.
