# Continue — начать/продолжить сессию

Триггеры: «продолжаем», новая сессия.

1. Прочитать **только** `START-HERE.md`.
2. Выполнить `git log -5 --oneline` и `git status --short`.
3. Если часть B старше последнего коммита или есть незакоммиченные изменения — доверять git и явно сказать об этом пользователю.
4. Кратко пересказать состояние, максимум 8 строк: активная задача, что сделано, что не закоммичено, следующий шаг, тесты.
5. Ждать команду пользователя. Ничего не редактировать и не доделывать самовольно.
