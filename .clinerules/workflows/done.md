# Done — закрыть шаг или задачу

Триггеры: шаг или задача завершены; команда `/done`.

1. `npm test` и `npm run typecheck` — оба должны пройти.
2. Обновить «Прогресс» в файле задачи: сделано / тесты / следующий шаг, максимум 15 строк, закрытое свернуть.
3. Если изменились архитектура, правила или формулы — обновить соответствующий документ из `docs/` (при необходимости `docs/battle.md`, `docs/architecture.md`, `docs/combat-formula.md`) и добавить ADR в `docs/decisions.md`.
4. Перезаписать часть B `START-HERE.md`. В «Тронутых файлах» — только файлы текущей задачи, без мета-файлов. В «В процессе» — только незавершённая работа по задаче, без истории про мета-настройку.
5. `npm run check` — исправить все предупреждения.
6. Коммит с понятным сообщением (не `wip`), затем `git push origin main` без `--force`.
7. Отчёт пользователю — максимум 8 строк: что сделано, тесты, что дальше.
