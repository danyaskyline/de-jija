# Handoff — передать контекст в новый чат

Триггеры: «лимит», «handoff», «переходим в другой чат».

1. Остановить работу, новых правок не начинать.
2. Перезаписать ЧАСТЬ B в `START-HERE.md` целиком (не дописывать), максимум 30 строк: активная задача, цель, сделано, в процессе, следующий шаг, тронутые файлы, как проверить, тесты, подводные камни, открытые вопросы, дата и модель. Часть A не трогать.
3. Если добавлялись/удалялись/переименовывались файлы — `npm run map`.
4. Коммит `wip: handoff — <кратко о чём>`.
5. `git push origin main` — без `--force` / `--force-with-lease`.
6. Если тесты красные — это допустимо для wip, но в части B указать, какие именно и почему.
7. Вывести пользователю готовое сообщение для нового чата с ЧИСТОЙ ссылкой (raw.githubusercontent.com):

```
Продолжаем работу над de-jija. Прочитай START-HERE.md:
https://raw.githubusercontent.com/danyaskyline/de-jija/main/START-HERE.md
Там постоянные правила и текущее состояние. Дальше читай только то, что реально нужно.
```
