DEV-TOOL: боевая песочница de-jija

Инструмент разработчика (DEV-TOOL). Страница /debug/battle-sandbox: не часть игрового клиента, ничего не сохраняет. Она НЕ считает ничего сама — ни соседей, ни расстояний, ни урона, ни ответок: страница только собирает настройки, отправляет команды /debug/battles/… и показывает присланный ответ. Все правила живут на сервере в Battle (docs/conventions.md, 019). В NODE_ENV=production роут НЕ монтируется (DEV-TOOL: not mounted in production).
Формульная песочница (разбор одного удара) осталась на /debug/combat-sandbox.

Инструменты

Очередь ходов

«Ждать» и «Завершить ход» работают для текущего юнита. Скорость меняется для любого выбранного юнита — так проверяется спешка и замедление.

Поле

Загрузка…
Клик по юниту — выбрать и показать допустимые цели. Клик по подсвеченной цели — удар. Клик по пустому гексу или перетаскивание юнита — поставить на место. Клик по пустому месту поля — снять выделение.

Выбранный юнит

Ничего не выбрано
